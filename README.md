# Project 1: Build Your Personal Website with AI!
In this project, you will leverage AI and your knowledge of HTML and CSS to build a simple, single-page personal website that will showcase your projects.

You will use AI to help you brainstorm design ideas, apply web development best practices, and troubleshoot issues, bringing your vision to life on screen! 

Launch a Codespace to get started. **Remember to Commit and Push** your project changes to GitHub from Codespaces to prevent losing progress.

---

## My portfolio

A single-page portfolio (HTML and CSS only) presenting four applications. Each one follows the same story: original idea → problems → what I learned → where it is now → end goal.

| Project | Status | Code |
| --- | --- | --- |
| Roadleaf: offline audio reader for Android | Public | [Audio_Reader-travel](https://github.com/fdmcadmin/Audio_Reader-travel) |
| Forever DM Combat: D&D combat extension for Owlbear Rodeo | Public | [fdmc-forever-dm-combat](https://github.com/fdmcadmin/fdmc-forever-dm-combat) |
| Unified AI Dashboard (Black Hole workstation) | Private, in development | screenshots on the page |
| Reality Engine | Private, in design | described on the page |

### Files

- `index.html`: the page (nav, header, about, skills, projects, contact)
- `style.css`: dark dashboard styling, flexbox only, with comments
- `img/project-emblem.webp`: the project image; `img/dashboard/`: dashboard screenshots

### Preview and save in Codespaces

1. Open the Codespace, right-click `index.html` and choose **Open with Live Server** (the dev container installs it).
2. After editing, open **Source Control**, write a message, **Commit**, then **Sync Changes** (push). Work that stays only in the Codespace isn't saved to this repository, which is how Project 1's first version ended up uploaded as a zip in a separate repo.
